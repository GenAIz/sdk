# Genaiz SDK Toolkits

## Modules

### [Genaiz SmartFunction Kit](genaiz/README.md)

Handles building, debugging, running, testing and publishing Smart Functions to Genaiz' platform

### [Genaiz SmartFunction Wiremock Testing](wiremock/README.md)

A series of utility compose targets which can be used to test the various commands of the Genaiz SmartFunction Kit.
